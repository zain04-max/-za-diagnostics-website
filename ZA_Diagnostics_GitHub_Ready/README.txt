# ZA Diagnostics website

Ready-to-upload static website for ZA Diagnostics.

## Included
- Professional responsive one-page website
- ZA Diagnostics logo and supplied job photos
- Services and package pricing from the supplied poster
- Travel policy from the supplied poster
- Click-to-call phone link
- WhatsApp booking form with pre-filled customer details
- Google Business Profile button
- Instagram / TikTok links
- Mobile-friendly design in ZA Diagnostics black/lime style

## Publish
Upload the contents of this folder to any static web host. No server/database is required.

Before publishing, check the social links and Google Business link on the live site. The Facebook link is currently the general Facebook homepage because a specific Facebook profile/page URL was not supplied.
